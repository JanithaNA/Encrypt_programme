# Text Encryption & Decryption Tool
A simple yet effective Python-based GUI application that allows users to encrypt and decrypt text using Base64 encoding. Built with Tkinter, this tool provides an easy-to-use interface for securing your text messages with password protection.


https://github.com/user-attachments/assets/8ce60f99-adaa-4d19-aec9-7103339cc064


 Features
🔒 Encrypt Text - Convert plain text into Base64 encoded format
🔓 Decrypt Text - Decode Base64 encoded text back to readable format
🔑 Password Protected - Requires password authentication (default: 123)
🎨 User-Friendly GUI - Clean and intuitive Tkinter interface
♻️ Reset Button - Quickly clear input fields
💻 Lightweight - No external dependencies beyond Python's standard library

🛠️ Tech Stack
Language: Python 3

GUI Framework: Tkinter
Encoding: Base64 (built-in base64 module)
